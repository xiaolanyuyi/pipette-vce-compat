# 移液枪 × 原版化学扩展 兼容补丁（一键配平版）

MOD ID：`pipette_vce_compat`　版本：**2.0.0**　游戏版本：0.46D

安装/卸载只需增删本文件夹（已放在 `Probably Stolen\\Mods\\pipette_vce_compat\\`）。

## 这个补丁干什么：一键配平

原版化学扩展（VCE）的配方都要求**固定化学计量比**（1:1、1:3、1:4、10:1、1:10…）。手动量体积很容易加多或加少：
酸加多了梦毒不生成、硅胶加少了污染物除不干净、还原剂加多了浪费。
本补丁给自动移液枪（超级移液枪）补 18 条**配平规则**：

> **吸满试剂 → 拖到目标容器一次 = 自动补到配方要求的比例；已经配平了就不动作（不会过量）。**

补的是"试剂量"，**不是**替你瞬间完成反应：液体比例配好后，仍然由原版化学扩展自己的
每秒/夜间结算去反应（保持它原本的速率与平衡，不算作弊）。这和移液枪内置的
"酒精补平""脂键补平"是同一套机制（`topup` / `conversion:false`）。

## B. 给内置模式追加的 11 条配平阶段

| 内置模式（枪内） | 目标里要有 | 配平到 |
|---|---|---|
| 酸 | 梦帽+梦魇萃取液 | 原版酸 ≈ 萃取液总量 ×2.5%（梦毒要求 0.5–5%） |
| 酸 | `vce_alkaloid` 生物碱 | 原版酸 = 生物碱 ×10%（快克因成盐 10:1；含水 >1% 时不动作） |
| 酸 | `vce_water_glass` 水玻璃 | 原版酸 = 水玻璃 ×1（析出硅胶 1:1） |
| 酸 | 甲苯 + 硝酸 | 原版酸 ≈ 混液总量 ×10%（硝化催化，需已有硝酸） |
| 酸 | 酒精 + 乙酸 | 原版酸 ≈ 混液总量 ×1%（酯化催化，需已有乙酸） |
| 酸 | 开盖核废料桶的废燃料 | 原版酸 = 废燃料 ×1（溶解） |
| 碱 | `vce_quartz` 石英 | 碱 = 石英 ×1（制水玻璃 1:1） |
| 碱 | `vce_nitric_acid` 硝酸 | 碱 = 硝酸 ×1（中和 1:1） |
| 碱 | `ia_acetic_acid` 乙酸（无原版酸/硝酸时） | 碱 = 乙酸 ×1（中和 1:1） |
| 酒精 | `vce_capsaicin` 辣椒素 | 酒精 = 辣椒素 ×4（辣酯满产条件） |
| 还原剂 | `nc_pu_dissolved` 溶解钚 | 还原剂 = 溶解钚 ×10（钚萃取 1:10） |

> 说明：topup 的"比例"是相对**目标里已有的底物量**算的，所以先放底物、再拖试剂；
> 枪容量最大 100 mL，大体积（比如核废料桶要 500 mL 酸）需要多拖几次，每次都会只补"还差的部分"。

## 核废料后处理的推荐顺序（配平按这个顺序最省）

1. **浓酸**（枪内原版酸）→ 拖到开盖桶：补到与废燃料 1:1（注意 VCE 要求酸占非放射性液体 ≥98%，所以先加酸）。
2. 等溶解出 `nc_pu_dissolved` 后，**还原剂** → 补到溶解钚的 10 倍。
3. **乙酸乙酯** → 补到裂变产物的 2 倍。
4. 放射性归零前，**水玻璃** → 补到放射性液体总量 1:1，然后加热到 300°C 玻璃固化。

2. 启动游戏时日志会先出现 `[pipette-vce-compat] init pipette_vce_compat v2.0.0` 和

   - `[pipette-vce-compat] hooked PenPipette.PipetteTransfer.OnTarget (opened-barrel containment)`

4. 如果**整局游戏都没有** `hooked ...` 这一行，说明桶守卫没装上（配平规则不受影响），请把日志发出来；

## 游戏内快速自检

- 容器里放甲苯 → 用吸满**硝酸**的 hydra 拖一次：硝酸变成甲苯的 3 倍；**再拖一次**应提示"已达配平"且不增加。
- 容器里放酒精 → 用吸满**乙酸**的 hydra 拖一次：乙酸 = 酒精。
- 容器里放辣椒素+酒精 → 用吸满**酒精**的 hydra 拖一次：酒精 = 辣椒素 ×4。
- 容器里放生物碱 → 用吸满**酸**的 hydra 拖一次：酸 = 生物碱 ×10%（含水 >1% 时不动作）。
- 碱+化学污染物 → 吸满**生石灰**拖一次：生石灰 = 污染物；等苛化跑完，污染物被清掉。
- 酸（≥80%）+化学污染物 → 吸满**硅胶**拖一次：硅胶 = 污染物/4；100°C 以上开始脱氟。
- 开盖核废料桶 → 吸满**原版酸**拖几次：每次只补"还差的量"。
- 用普通移液枪去吸开盖核废料桶：只会吸到允许离开的液体（钚萃取液/可蒸发非放射性液体），日志出现
  `blocked N VCE liquid(s) from leaving the opened nuclear waste barrel through a pipette`。


## 常见问题：生石灰纯度到不了 50%？（稀释试剂也能拿来配平）

**结论：游戏里没法把生石灰和矿物质/物理污染物分开，所以矿石路线的生石灰必然 <50%。这不是 bug，是数据决定的。**

- 矿石粉碎后的组成是固定的：方解石 ~12–15 mL、石英 ~14–17 mL、矿物质 ~6–8 mL、重金属 ~4–5.5 mL、物理污染物 ~4–6 mL（`OreItems.cs:14-19`）。
- 能用的滤芯只有两种孔径：Kotton 150（只拦粒径 ≥150 的石英/碎屑，`AmenitiesItemDirectory.cs:418-424`）、水滤芯 22（拦粒径 ≥22 的固体，`AmenitiesItemDirectory.cs:436-442`）。
- 粒径：方解石/生石灰/碳酸钙/硅胶=100、石英=200、矿物质=30、物理污染物=100、碎屑=200、重金属=12、酸碱=5（`OreLiquids.cs:15-23`、`Liquid.cs`）。
  → 水滤芯孔径 22 会把**生石灰自己也滤掉**（100≥22），Kotton 只滤石英，中间没有能"只留生石灰"的孔径；HPLC 又要求样品无颗粒。所以分离不了。
- 煅烧只把方解石变生石灰并损失约 45% 体积（`OreReactions.cs:43-54`），所以矿石路线的生石灰占比通常就是 **25–30%**（你截图里的 27.68% 正是如此）。只有"纯方解石"才能煅烧出接近 100% 的生石灰，而游戏里拿不到纯方解石。

**补丁的处理：把"检测阈值"降到稀释试剂也能用**（移液枪要先能吸起来才谈得上配平）：

| 模式 | 主液体占比阈值 | 该试剂理论上限 |
|---|---|---|
| 生石灰 | 12% | 矿石路线 ~25–30%，纯方解石 100% |
| 硅胶 | 15% | 最高 50%（与碎屑 1:1 生成） |
| 硝酸 | 15% | 溶气上限 40% |
| 乙酸 | 15% | 干馏最高 ~33%（乙酸:碎屑=1:2） |
| 梦帽萃取液 | 20% | 萃取产率 0.5，副产物占另一半 |
| 乙酸乙酯 | 25% | 可接近 100%（1:1 反应后体积减半） |
| 水玻璃 | 30% | 可接近 100% |

同时把新模式的优先级降到 65（内置酸/碱/酒精/矿物质模式是 70–110），**有内置模式能匹配时优先走内置模式**，不会抢移液枪原有行为。

**代价与用法（重要）**：移液枪吸稀释试剂是"按比例"吸的，所以生石灰瓶子里的矿物质/物理污染物/重金属会跟着一起进目标容器。这在 VCE 的标准流程里能收尾：
1. 苛化完成后，用**水滤芯（孔径 22）**过滤碱：矿物质(30)、物理污染物(100)、剩余生石灰(100)、碳酸钙(100)、碎屑(200) 都会被滤掉；重金属(12) 会随碱自行沉降成碎屑。
2. **注意碱占比**：VCE 苛化要求碱占总液量 ≥50%，稀释试剂会额外带进体积，可能把碱稀释到 50% 以下（苛化就停了）。对策：先多加碱、或先把杂质滤掉再补生石灰、或分几次少量配平。
3. 只想要精确控量、不想带杂质：用**普通移液枪**（可调剂量）手动加生石灰。

## 想要"拖一下瞬间反应完"的旧版本？

本补丁 1.1.0 曾提供"瞬间转化"规则（一次拖拽直接把反应做完）。文件保留在
`optional\\instant-reactions.json`：把它复制并覆盖到 mod 根目录的 `PipetteReactions.json` 即可切回。
区别：瞬间版会跳过 VCE 自己的反应速度（相当于加速器）；配平版只负责把量配对，反应仍按 VCE 节奏走。

## 设计边界 / 已知限制

- **配平 = 调比例，不是万能加液**：移液枪的模式由"吸到什么主液体"决定，没有选择 UI；要自由加任意体积请用普通移液枪。
- **配平规则只作用于 VCE 有明确化学计量比的步骤**。以下没有做配平，需要玩家自己控制：
  * 成型机/机器配方是"绝对体积阈值"（如注射剂 ≥5000 µL、炸药 ≥250 mL），topup 只能调比例，无法表达绝对体积；
  * 发酵水解要求原版酸占**总液量** ≥0.5%（topup 只能按底物比例算），请手动加；
  * 电解、蒸馏、HPLC、分液漏斗、复装机、成型机都在机器内部结算，移液枪只负责把液体搬到位。
- 头孢菌素 C 的基因组/纯度数据原版化学扩展自己已经反射挂上了 `OnTarget`，本补丁不重复处理。
- 移液枪的 hydra 反应/配平路径不调用 `OnLiquidContainerPourInto`、不过滤、不混温（移液枪固有行为），
  容器价格/水质标签可能延后一 tick 刷新。
- 若移液枪将来改动 `PipetteTransfer.OnTarget` 签名，DLL 桶守卫会自动跳过（日志 Warn），配平规则不受影响。
- 本补丁不处理：钚液体直接倒进酒瓶不会加"核子饮料"标记（VCE 只给"用钚安瓿扎酒"加）。
